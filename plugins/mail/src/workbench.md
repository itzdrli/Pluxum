# 邮件

论坛通过 SMTP 发送邮件：通知（例如有人回复了你的主题）和绑定邮箱时的验证码。服务器、端口、加密方式、用户名和发件人在“配置”里修改，保存后立即生效。

用户在自己的个人资料页填写邮箱，输入收到的验证码后才会收到通知，也可以随时关闭。

::slot[status]

## 测试

用当前设置发一封测试邮件，确认服务器、账号和发件地址都可用。

::slot[sendTest]

## SMTP 密码

密码只存进本插件的 Vault 记录 `smtp-password`，不进入配置，也不会显示出来。

::slot[setPassword]

::slot[clearPassword]
