# 邮件

论坛通过 SMTP 发送各种提醒（例如有人回复了你的主题、提到了你）。服务器、端口、加密方式、用户名和发件人在“配置”里修改，保存后立即生效。

论坛不自己保存邮箱：邮件发到用户登录时身份提供方（OIDC）给出的已验证邮箱。身份提供方没有给邮箱的用户收不到邮件。用户可在个人资料页关闭邮件通知、选择邮件语言。

::slot[status]

## 模板

在“配置 → 邮件模板”设置默认语言，并分别编辑简体中文和英文模板。留空用内置文案。模板是纯文本，可换行。

- `{siteName}` 是论坛名称。
- `{title}` 是按收件人语言生成的通知标题。
- `{body}` 是内容摘要，没有摘要时为空。

## 测试

选择语言，发一封测试邮件，或发一条示例通知看模板效果。

::slot[sendTest]

## SMTP 密码

密码只存进本插件的 Vault 记录 `smtp-password`，不进入配置，也不会显示出来。

::slot[setPassword]
