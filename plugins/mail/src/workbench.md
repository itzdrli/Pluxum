# 邮件

论坛通过 SMTP 发送各种提醒（例如有人回复了你的主题、提到了你）。服务器、端口、加密方式、用户名和发件人在“配置”里修改，保存后立即生效。

论坛不自己保存邮箱：邮件发到用户登录时身份提供方（OIDC）给出的已验证邮箱。身份提供方没有给邮箱的用户收不到邮件。用户可以在自己的个人资料页关闭邮件通知。

::slot[status]

## 测试

用当前设置发一封测试邮件，确认服务器、账号和发件地址都可用。

::slot[sendTest]

## SMTP 密码

密码只存进本插件的 Vault 记录 `smtp-password`，不进入配置，也不会显示出来。

::slot[setPassword]
