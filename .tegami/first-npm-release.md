## First release on npm

The Pluxum forum plugins and their shared domain package are published as
`@pluxum/*`, all on one version. Install them into a Pluxel host alongside the
`@pluxel/*` packages they declare as peers. Each package ships its built plugin,
Workbench artifacts and type declarations.
